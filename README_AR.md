# إنجاز — تطبيق مهام يومي يعمل دون اتصال

## الهوية والتوافق

- `applicationId` ثابت حرفياً: `com.injaz2.app`.
- `compileSdk`: `36`، و`targetSdk`: `35`، و`minSdk`: `24`.
- Java/Kotlin target: `17`، و`desugar_jdk_libs` مفعّل.
- الإصدار الحالي: `1.0.2+3`، وهو أعلى بدرجة واحدة من النسخة السابقة `1.0.1+2`.
- لم يتم إنشاء مفتاح توقيع جديد. إعداد release الحالي يستخدم توقيع debug المحلي؛ وللتحديث فوق APK منشور يجب استخدام مفتاح التوقيع الأصلي نفسه.

## الميزات

- أزرار حالة المهمة أيقونتان فقط: ✓ للحسم و✕ لعدم الإنجاز، مع Tooltip دون نص داخل الزر.
- تتحول بطاقة المجلد وأيقونته إلى اللون الأخضر وتظهر شارة عند اكتمال مهام اليوم، دون شطب اسم القائمة.
- إشعار مستقل لكل مهمة في وقتها الحقيقي، وليس وقت أول مهمة في القائمة.
- إجراءات الإشعار: الحسم، لم يتم، التأجيل ساعة، التأجيل إلى بداية اليوم التالي عند 00:00، ووقت مخصص من داخل التطبيق.
- إلغاء إشعار المهمة عند حسمها أو حذفها، وحفظ وقت التأجيل في SQLite لمنع تكرار الإشعار بعد إعادة التشغيل.
- تقرير يومي مستقل قابل للتفعيل وتحديد وقته، يعرض إجماليات `done/notDone/pending` وتفاصيل كل قائمة.
- اختيار تاريخ المهمة وعرض الأيام السابقة واليوم والأيام المستقبلية من سجل التطبيق.
- التكرار اليومي وأيام أسبوع محددة، مع حالات مستقلة للنسخ اليومية.
- تعديل المهمة المتكررة يحفظ occurrence السابقة ويبدأ التعديل على المستقبل فقط.
- حذف التكرار يعرض أيام الأسبوع ويسمح بإزالة أيام محددة أو حذف السلسلة.
- إعادة ترتيب القوائم والمهام بالسحب والإفلات مع حفظ الترتيب.
- SQLite عبر `sqflite` مع ترحيل محافظ من SharedPreferences دون حذف البيانات القديمة عند الفشل.

## التحقق

تم تنفيذ فحص نصي للملفات وإعدادات Android، والتحقق من:

```text
applicationId = com.injaz2.app
compileSdk = 36
targetSdk = 35
minSdk = 24
version = 1.0.2+3
```

لم تتوفر أوامر Flutter وDart في بيئة التنفيذ الحالية؛ لذلك فشلت الأوامر التالية بسبب عدم وجود `flutter`، ولم يتم الادعاء بنجاحها:

```bash
flutter pub get
flutter analyze
flutter test
flutter build apk --release
```

يجب تشغيلها في بيئة Flutter متوافقة قبل اعتماد APK للإنتاج. كما يجب اختبار التأجيل المخصص، إعادة تشغيل الهاتف، صلاحيات التنبيهات، والتوقيع على جهاز Android فعلي.
